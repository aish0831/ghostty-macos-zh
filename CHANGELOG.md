# Changelog

All notable changes are documented here. The project follows semantic versioning.

## 0.1.0 - 2026-10-09

- Add Ghostty 1.3.1 NIBArchive localization support.
- Reuse Ghostty's bundled official `zh_CN` gettext catalog.
- Add native macOS menu translation fallbacks.
- Add standalone app builder with a distinct bundle identifier.
- Add local ad-hoc signing, entitlement handling, and signature verification.
- Add tests, linting, CI, documentation, and contribution templates.
- Add repository privacy policy, metadata audit tooling, and SPDX source headers.
